Tugas Pendahuluan Modul 4: Pengenalan JavaScript

Kelas: D3-TT-01 | Ikuti instruksi pada setiap latihan untuk mempelajari dasar-dasar JavaScript untuk Website (Inline, Internal, dan Eksternal).

Latihan 1: Inline JavaScript (Interaksi Klik)

Instruksi: JavaScript paling mudah digunakan untuk membuat tombol merespons klik. Tambahkan atribut onclick="..." langsung pada tag <button> di bawah ini agar saat diklik, memunculkan popup alert bertuliskan pesan bebas (contoh: "Halo D3-TT-01!").

Latihan 2: Internal JavaScript (Manipulasi DOM Dasar)

Instruksi: JavaScript dapat mengambil elemen HTML dan mengubah kontennya secara instan (DOM Manipulation):

  1. Buat tag <script> tepat di bawah teks paragraf ini (masih di dalam file HTML).
  2. Gunakan document.getElementById("teks-ubah") untuk menyimpan elemen ke dalam variabel.
  3. Ubah tulisannya menggunakan properti .textContent = "Teks berhasil diubah oleh JS!"
  4. (Opsional) Ubah juga warnanya dengan .style.color = "blue"

Saya adalah teks asli, tolong ubah saya!

Latihan 3: Eksternal JavaScript (Membuat Aplikasi "Sapaan")

Instruksi: Praktik terbaik penulisan JavaScript adalah dipisah di file bereksistensi .js.

  1. Panggil file script.js dengan menyisipkan tag penghubung <script src="..."> di baris paling bawah dari file ini (sebelum tutup body).
  2. Buka file script.js lalu ikuti instruksi yang ada di sana untuk membuat tombol penghasil pesan selamat datang berdasarkan nama yang diketik.
