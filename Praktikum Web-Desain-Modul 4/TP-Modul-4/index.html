Latihan 1: Inline JavaScript (Interaksi Dasar)

Instruksi: Tambahkan atribut onclick="..." langsung pada tag <button> di bawah ini agar saat diklik, memunculkan popup alert bertuliskan pesan bebas (contoh: "Halo D3-TT-01!").

Latihan 2: Internal JavaScript (Variabel, Tipe Data & Operator)

Instruksi:

  1. Buat tag <script> tepat di bawah paragraf ini.
  2. Di dalamnya, buat variabel string let nama = "[Nama Anda]" dan variabel angka let tahunLahir = [Tahun Lahir Anda] serta let tahunSekarang = 2024.
  3. Gunakan operator matematika (pengurangan) untuk membuat variabel umur: let umur = tahunSekarang - tahunLahir;
  4. Tampilkan hasilnya di elemen HTML di bawah ini menggunakan document.getElementById("info-biodata").textContent.
